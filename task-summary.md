# Project Title

UGC Ad Generator

# Objective

To create an AI-powered tool that generates User Generated Content (UGC) marketing materials for businesses and products using prompt engineering.

# Features

* Viral Hook Generation
* UGC Ad Script Generation
* Call-To-Action (CTA) Suggestions
* Social Media Caption Generation
* Platform-Based Content Creation
* Modern and Responsive Interface

# Tools Used

* Lovable
* ChatGPT
* GitHub

# Outcome

Successfully designed and developed a UGC Ad Generator that creates engaging marketing content, including hooks, scripts, CTAs, and captions for social media platforms.
